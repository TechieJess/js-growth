# Secret Lab: Hulk Transformation 🟢

An interactive DOM manipulation project that transforms Bruce Banner into the Hulk 
and back again with the click of a button.

## Live Demo
> Click Transform to switch between states endlessly

**State 1: Bruce Banner**
- Yellow background `#ffb300`
- 60px font size, 2px letter spacing

**State 2: Hulk**
- Green background `#70964b`
- 130px font size, 6px letter spacing

## Built With
- HTML
- CSS: transitions, transforms, box-shadow
- JavaScript: DOM manipulation, event listeners, boolean state tracking

## Concepts Used
- `document.querySelector()`
- `addEventListener()`
- `element.style`: dynamically changing CSS with JS
- `element.textContent`: dynamically changing text with JS
- Boolean flag for state toggling
- CSS `transition` for smooth animations

## What I Learned
How to manipulate the DOM with JavaScript to dynamically change 
both content and styles on a page in real time.
