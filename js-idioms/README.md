# JS Idioms 💬

A JavaScript program that displays a number-based idiom depending on user input.

## How It Works
1. User is prompted to enter a number from 1 to 10
2. If the number is invalid, the prompt repeats until a valid number is entered
3. The matching idiom is displayed via an alert

## Idioms
| Number | Idiom |
|--------|-------|
| 1 | Back to square 1 |
| 2 | Goody-2-shoes |
| 3 or 6 | Two's company, three's a crowd |
| 4 or 9 | Counting sheep |
| 5 | Take five |
| 7 | Seventh heaven |
| 8 | Behind the eight-ball |
| 10 | Cheaper by the dozen |

## Concepts Used
- `prompt()` and `alert()`
- `Number()` for type conversion
- `while` loop for input validation
- `if/else` statements
- `switch` statement (commented as alternative approach)

## What I Learned
How to use a `while` loop to repeatedly prompt a user until 
valid input is received, and how `switch` statements compare 
to `if/else` for handling multiple conditions.
